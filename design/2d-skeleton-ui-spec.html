01 / Color

配色系统

基于 Material 3 色调算法生成：一个种子色 #6750A4 展开为 Primary / Secondary / Tertiary / Neutral / Neutral-Variant / Error 六条色调带，界面只使用语义角色，不直接使用原始色值。这样在 Android 12+ 的动态取色（Material You）下可以整体替换而不破坏对比度。

语义角色与应用场景

颜色分工

角色界面中的位置说明
Primary骨骼链、关节控制点、选中行、主按钮代表「结构」——用户正在编辑的骨架本身
Primary Container当前导航项、FAB、选中列表行大面积浅色块，避免与画布中骨骼线抢视觉
Secondary贴图部件缩略图、次级面板标题区分「皮肤」与「骨架」两层概念

深色模式

深色模式下主色升到 tone 80、容器降到 tone 30，保证 4.5:1 对比度；画布背景使用 #1D1B20，骨骼贴图改为 #E6E0E9 与深色画布形成 12:1 对比，骨骼线降到 tone 90 以免过曝。

02 / Typography · Shape

字体与形状

英文与数字用 Roboto，中文回落到 Noto Sans SC。只使用 400 与 500 两个字重，靠字号与颜色建立层级，避免在深色画布上出现笔画糊掉的现象。所有数值（角度、帧号、坐标）使用等宽字体，防止拖动时数字宽度跳动。

03 / Iconography

图标风格

统一采用 Material Symbols Rounded 风格：24dp 画板、2dp 描边、圆头圆角端点、几何构造。默认不填充（FILL 0），被激活的导航项和状态按钮切换为填充版（FILL 1），这是 Material 3 表达选中态的标准方式，不需要额外的背景色。

画板与描边24×24 画板，四周留 2dp 安全区，笔画落在 2dp 整数格上
线性 / 填充两态未选中用线性（on-surface-variant），选中用填充 + primary
单色约束一个图标只用一种颜色；多色仅出现在骨骼贴图本身
触控与容器图标本体 24dp，触控热区不少于 48dp，容器圆角 10–12dp
04 / Character

骨骼人物的视觉呈现

角色资产遵循「三层分离」原则：贴图层（导入的骨骼插画）、骨架层（主色关节链）、控制层（手柄、旋转弧、标签）。三层可独立开关，任何时候都不允许把控制器画进贴图里——这样导出时才不会被烘焙进去。骨骼插画按部件切分，用米白 #F4F1EA 填充配 #B4B2A9 描边，在深色和浅色画布上都能保持轮廓。

① 原始素材导入的整张骨架图，尚未切分
② 装配态叠加主色骨骼链与关节锚点
③ 选中与旋转选中骨骼加粗发光，显示旋转弧
④ 部件归属按切图分组的着色视图

深色画布中的呈现

深色画布贴图升至 #E6E0E9，骨骼链用 tone 80
为什么不用纯黑背景

纯黑 (#000) 会让米白骨骼产生强烈余晖，长时间绑骨容易视觉疲劳。使用 #1D1B20（Neutral 10）配合 8dp 点阵网格，既保持暗室感，又让骨骼轮廓有柔和边界。

背景 #1D1B20 网格 #322F35 骨骼 #E6E0E9 骨骼链 #D0BCFF

动效参数

所有动效遵循 Material 3 motion：标准曲线 cubic-bezier(0.2, 0, 0, 1)，强调曲线用于进入屏幕的元素。唯一例外是画布与时间轴的拖动反馈——必须 0ms 跟手，任何缓动都会破坏「直接操纵」的手感。
